Based in Germany. Open to **Unity/XR, C#/.NET and full-stack development roles**. [Connect on LinkedIn](https://www.linkedin.com/in/niklas-schmitt-7019872bb/).

## Unity, Games & XR

- **[Smaller Games RPG](https://github.com/Tigertycoon/smaller-games-rpg)** — A reusable Unity/C# package for configurable stats, party progression and turn-based combat, with 54 Unity regression tests.
- **[GroupAR](https://github.com/Tigertycoon/groupar)** — An AR Foundation content-pipeline prototype connecting a Unity player, a Node.js API and a TypeScript media worker, with dynamic image libraries and versioned content manifests.
- **[Rift Hunt](https://github.com/Tigertycoon/rift-hunt)** — A Unity exploration-game prototype with configurable story trails, location gates, AR adapters and seven minigames; an included preview uses simulated tracking.
